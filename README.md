## ✨ Features

* 📊 **Real-Time Balance Calculation:** Instantly view your total balance, income, and expenses at a glance.
* ➕ **Quick Transaction Logging:** Easily add, categorize, and delete income or expense entries.
* 🔍 **Smart Filtering & Search:** Filter transactions by category, date, or transaction type.
* 💾 **Persistent Storage:** Automatically saves your financial data locally so you never lose track on page reload.
* 📱 **Responsive UI:** Clean, mobile-first interface designed for seamless use across desktop, tablet, and phone screens.
